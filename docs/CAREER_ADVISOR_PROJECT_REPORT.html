1. Executive Summary & Value Proposition

Career-Advisor is an enterprise full-stack engineering solution that bridges the critical gap between higher education, developer upskilling, and hiring expectations. Modern computer science students and engineers face fragmented learning workflows: career roadmaps live on static websites, coding practice occurs in separate judge platforms, mock interviews are conducted informally, resumes are formatted without automated skill gap detection, and self-study lacks accountability.

Career-Advisor unifies these disciplines into a coherent, production-grade cloud platform powered by a decoupled architecture:

  • End-to-End Career Discovery & Guidance: 7 curated career tracks with match scoring, beginner-to-advanced milestone roadmaps, and persistent progress tracking.
  • Diagnostic Assessment & Skills Portfolio: Automated quiz evaluation assigning candidates to skill tiers, backed by an isolated skills matrix.
  • In-Browser Coding IDE: 22 curated DSA problems across 10 core computer science topics featuring a sandbox code simulator, line numbers, and custom test case inspectors.
  • Timed Technical Mock Interviews: Server-authoritative timer, real-time anti-cheating window tracking, automated grading, and concept-tagged explanations.
  • Server-Side Resume Analyzer: Magic-byte validated, in-memory stream text parsing for PDF and DOCX documents with canonical skill normalization, roadmap gap extraction, and user-confirmed skill synchronization.
  • Real-Time Human Collaboration: Bi-directional STOMP over WebSocket communication for peer messaging and admin support tickets, with typing indicators, read receipts, and multi-session presence tracking.
  • WebRTC Peer-to-Peer Calling: HD Audio and Video calling featuring a server-authoritative state machine with anti-race guards and a floating Picture-in-Picture draggable UI.
  • Unified Career Intelligence & AI Action Planner: A 6-dimensional mathematical readiness model synthesizing skills, roadmap progress, quiz score, DSA telemetry, interview mastery, and resume alignment into a 0–100 score with targeted, explainable 3–5 step action plans.
  • Adaptive Weekly Study Planner: Converts career goals into time-boxed, 7-day study routines tailored to user daily budgets, preferred study windows, and active days.
  • Longitudinal AI Progress Coach: Weekly accountability engine tracking cross-pillar momentum, identifying strengths, weaknesses, and weekly trend directions (IMPROVING, STABLE, DECLINING).

6. Real-Time Communication Ecosystem (WebSocket & WebRTC)

The platform provides a dual-layer real-time communication stack: lightweight JSON messaging over STOMP WebSockets and direct high-throughput audio/video streaming via peer-to-peer WebRTC.

STOMP over WebSocket Architecture

  • Handshake & Security: Configured at endpoint /ws with SockJS fallback. WebSocketSecurityInterceptor extracts the JWT token from the STOMP CONNECT frame header (Authorization: Bearer ) and authenticates the principal in the WebSocket session attributes.
  • Channel Authorization: Subscriptions to /topic/conversations/{id} are intercepted. The user identity is checked against ConversationParticipant records; unauthorized users receive an error and the frame is rejected.
  • Presence Service: Uses thread-safe in-memory tracking via ConcurrentHashMap> to manage multi-tab and multi-device sessions for each user. When the last session disconnects, a USER_OFFLINE payload broadcasts to /topic/presence.
  • Typing & Read Receipts: Emits lightweight transient events to /topic/conversations/{id}/typing and /topic/conversations/{id}/read without database persistence overhead.

WebRTC Audio & Video Calling Architecture

  • Zero Backend Media Relay: Media streams (SRTP/UDP) flow strictly peer-to-peer between candidate browsers. The Spring Boot backend acts strictly as an authoritative signaling coordinator and state machine.
  • Server-Authoritative State Machine: Call states transition strictly through allowed vectors: 
    RINGING ──> ACCEPTED ──> ENDED / FAILED
   │
   └──> REJECTED / CANCELLED / MISSED / EXPIRED
  • Anti-Race Conflict Guard: The backend checks callSessionRepository.findActiveCallForUser(userId) before initiating a new call. If a call is already active, it rejects the request with HTTP 409 Conflict (CALL_ALREADY_ACTIVE).
  • Auto-Ringing Expiration: Unanswered incoming calls automatically transition to MISSED with reason TIMEOUT after 45 seconds.
  • Draggable Picture-in-Picture UI: CallOverlay.tsx renders active calls in a floating draggable overlay with local PiP stream, animated audio visualizer waves, live duration counters, and device permission error handling (NotAllowedError, NotFoundError).

7. Document Processing & In-Memory Resume Extraction Engine

The Resume Analyzer provides secure, server-side extraction of candidate technical profiles from binary documents without disk persistence vulnerabilities.

File Upload Security & Validation

  • Magic Byte Verification: Validates file headers in memory:
    • PDF: Must begin with magic byte sequence %PDF (hex 0x25 0x50 0x44 0x46).
    • DOCX: Must begin with ZIP magic byte sequence PK (hex 0x50 0x4B 0x03 0x04).
  • Memory Stream Extraction: Files are read via MultipartFile.getInputStream() directly into Apache PDFBox (Loader.loadPDF) or Apache POI (XWPFDocument). Files are never written to temporary disk paths, preventing path traversal attacks.
  • Size Limits: Hard-capped at 5MB per file and 10MB per request with clean error handling for MaxUploadSizeExceededException (HTTP 413).

Canonical Skill Extraction & Gap Detection

  • Canonical Dictionary: 35+ industry skills categorized into Frontend, Backend, Database, Cloud & DevOps, Programming Languages, and Core CS.
  • Alias Normalization: Maps variations to canonical names (e.g., "react.js", "reactjs" $ ightarrow$ "React"; "k8s" $ ightarrow$ "Kubernetes").
  • Confidence Scoring: Computes an 80%–99% confidence score based on term frequency, section context (e.g., in a "Technical Skills" section vs an email address), and word boundary matching.
  • Skill Synchronization: Users review extracted competencies on /resume and click "Add All Confirmed Skills" to persist them directly into user_skills with a single click.

8. Multi-Dimensional Career Intelligence & Readiness Modeling

The Career Intelligence Engine unifies candidate performance across all 6 core pillars of the platform into a deterministic, mathematically grounded readiness score ($0 ext{--}100$).

Readiness Formula & Dimension Weights

Readiness Score = (Skills × 0.20) + (Roadmap × 0.20) + (Assessment × 0.15) + (DSA × 0.15) + (Mock Interview × 0.15) + (Resume × 0.15)
Dimension Weight Underlying Metric & Calculation Logic
Skills 20% Ratio of candidate's verified skills (user_skills) matching the target career track competencies.
Roadmap 20% Percentage of completed milestones in the candidate's chosen career curriculum.
Assessment 15% Diagnostic quiz score percentage and classified skill level.
DSA 15% Problems solved in the practice hub vs total curated problem catalog (22 problems).
Mock Interview 15% Average percentage score achieved across completed timed mock interviews.
Resume 15% Extracted technical skills from the latest uploaded resume matching target career competencies.

Readiness Tier Classification

  • NOT_STARTED (0–19%): Minimal platform engagement; initial assessment and skill setup recommended.
  • DEVELOPING (20–49%): Early foundations established; focus on core curriculum roadmaps.
  • PROGRESSING (50–74%): Solid competency; accelerating DSA problem solving and mock interview preparation.
  • JOB_READY (75–89%): High readiness; interview-ready with complete skill portfolios.
  • EXCEPTIONAL (90–100%): Top candidate tier; comprehensive mastery across all dimensions.

Goal-Oriented AI Action Planner (Phase 15B)

AiActionPlanService translates the 6-dimensional readiness analysis into 3 to 5 targeted, high-impact actions. Each action includes:

  • whyItMatters: Concrete diagnostic reasoning grounded in detected skill gaps.
  • expectedOutcome: Measurable improvement in career readiness.
  • estimatedEffort: Realistic time allocation (e.g., 30–60 minutes).
  • actionUrl: Direct application deep-link to execute the recommendation.

9. Adaptive Weekly Study Planner & Daily Time-Boxing Engine

The Weekly Study Planner (Phase 15C) translates career actions into a structured, daily study schedule with time-boxing and task lifecycle tracking.

Daily Time-Boxing Algorithm

  • User Study Preferences: Candidates configure daily study budgets (e.g., 60 minutes), preferred study windows (MORNING, AFTERNOON, EVENING, NIGHT, FLEXIBLE), and active study days (e.g., Mon–Fri).
  • Candidate Task Assembly: Tasks are prioritized based on detected skill gaps, balancing across Roadmap checkpoints, DSA practice, Review, and Timed Interviews.
  • Active Day Scheduling: Tasks are allocated to preferred days up to the daily minute budget.
  • Off-Day Maintenance: On non-preferred days, light 15-minute concept consolidation tasks are injected to maintain study streaks without causing burnout.
  • Task Lifecycle: Tasks transition cleanly: 
    PENDING ──> IN_PROGRESS ──> COMPLETED / SKIPPED
  • Streak Calculation: Automatically updates consecutive study days upon task completion.

10. Longitudinal AI Progress Coach & Trend Analysis

The AI Progress Coach (Phase 15D) provides weekly longitudinal accountability by tracking candidate performance across 4 key learning pillars.

Overall Progress Score Formula

Overall Progress Score = (Roadmap × 0.25) + (DSA × 0.25) + (Interview × 0.25) + (Planner Consistency × 0.25)

Longitudinal Trend Classification

Each weekly report compares metrics against prior periods to assign trend directions:

  • IMPROVING: Metrics increased by $ge 3%$ compared to historical baseline.
  • STABLE: Metrics maintained within $pm 2%$ variance.
  • DECLINING: Activity or scores dropped by $ge 3%$.
  • INSUFFICIENT_DATA: New candidate without prior weekly reports.

AI Chatbot Context Grounding

When candidates ask questions like "How am I doing this week?" in the AI Chatbot (/chat), the prompt is automatically grounded in the latest WeeklyProgressReport data, ensuring accurate coaching advice with zero hallucination.

11. Role-Based Access Control (RBAC) & Platform Governance

Platform security is enforced at both the API and database levels using Role-Based Access Control (RBAC):

  • Roles: ROLE_USER (standard candidate) and ROLE_ADMIN (platform administrator).
  • JWT Claim Embedding: The user's role is embedded in the signed JWT token payload (claims.put("role", role.name())).
  • Method & Endpoint Security: All administrative endpoints under /api/admin/** are protected with hasRole('ADMIN'). Standard user endpoints isolate data by JWT principal.
  • Elevation Prevention: The public registration endpoint (/api/auth/register) strictly sets Role.USER, completely preventing role elevation injection.
  • Admin Governance Console (/admin): Real-time platform KPI metrics, candidate search, profile inspection modals, and support ticket management.
